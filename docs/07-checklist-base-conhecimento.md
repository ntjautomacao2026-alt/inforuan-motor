# Checklist para o Ruan — base de conhecimento do atendimento

> Objetivo: a IA só responde o que estiver aqui. O que não estiver vai para um humano.
> Prazo para a entrega de sexta: **quinta, 01/10, 12h**.

## ⚠️ Regra de privacidade (vale para tudo)
**Não enviar** nomes, telefones, e-mails, CPF, prints com dados de pagamento, comprovantes, endereços ou fotos de perfil.
Em exemplos de conversa, trocar por `[CLIENTE]`, `[TELEFONE]`, `[EMAIL]`, `[VALOR]`. Se for print, cobrir esses dados antes de enviar.

## Formato preferido
Um documento (Google Docs ou texto) com uma seção por item abaixo. Respostas escritas **do jeito que você fala com o cliente**.

---

### 1. Perguntas mais frequentes (mínimo 15)
- [ ] Lista das perguntas que mais chegam, na linguagem do cliente
- [ ] Marcar as 5 mais comuns

### 2. Respostas que você já usa
- [ ] Para cada pergunta do item 1, a resposta que você manda hoje (texto pronto)
- [ ] Mensagens-padrão que você copia e cola (se existirem)

### 3. Acesso e entrega
- [ ] Como o cliente recebe o produto (e-mail da GGCheckout? de qual remetente? assunto?)
- [ ] Passo a passo para abrir o Google Drive **no celular** (o público tem 40+ anos)
- [ ] O que fazer se o e-mail não chegou (spam, e-mail digitado errado)
- [ ] Como baixar o PDF e como abrir a planilha Calculadora ("fazer uma cópia")
- [ ] Como usar o Meu Consultor Financeiro (Gem do Gemini): precisa de conta Google?
- [ ] Tempo normal até o acesso chegar depois do pagamento

### 4. Conteúdo e promessa de cada oferta
Para **Finanças Básico, Finanças Completo, Atualiza Básico, Atualiza Completo, Meu Consultor e cada order bump**:
- [ ] Promessa (em 1 frase)
- [ ] O que exatamente o cliente recebe
- [ ] Para quem é e para quem **não** é
- [ ] Preço atual (a IA **não** oferece desconto nem preço diferente)

### 5. Garantia e reembolso
- [ ] Prazo da garantia (7 dias?) e a partir de quando conta
- [ ] Como o cliente pede (a IA **não** executa reembolso; transfere para humano)
- [ ] Prazo para devolver o dinheiro no Pix e no cartão
- [ ] Texto que você usa hoje para responder pedido de reembolso

### 6. Problemas mais comuns
- [ ] "Paguei e não recebi"
- [ ] "O link não abre" / "pede permissão" / "pede login"
- [ ] "O Pix expirou" / "não consegui pagar"
- [ ] "Comprei duas vezes"
- [ ] "Não sei usar o Drive / o celular"
- [ ] Outros que se repetem

### 7. Objeções antes da compra
- [ ] Dúvidas e objeções mais comuns ("é confiável?", "é físico?", "serve para mim?", "por que tão barato?")
- [ ] Como você responde cada uma
- [ ] Onde o cliente pode ver o site, o CNPJ ou uma prova social (se existir)

### 8. Situações que exigem humano (confirmar ou ajustar)
A IA transfere automaticamente quando:
- [ ] Pedido de reembolso ou cancelamento
- [ ] Cliente irritado, ameaça, reclamação, Procon ou ReclameAqui
- [ ] Envio de comprovante, foto ou arquivo
- [ ] Pergunta fora da base
- [ ] Cobrança em duplicidade ou valor diferente
- [ ] Pedido explícito de falar com uma pessoa
- [ ] **Outros casos que você quer atender pessoalmente:** ____

### 9. Exemplos de conversas (anonimizados)
- [ ] 5 a 10 conversas reais bem resolvidas (dúvida, acesso, objeção)
- [ ] 2 a 3 conversas difíceis e como você resolveu

### 10. Tom de voz
- [ ] Trata por "você" ou "senhor/senhora"?
- [ ] Usa emoji? Quais?
- [ ] Assina com nome? Qual?
- [ ] Palavras ou expressões que **nunca** devem ser usadas

### 11. Operação
- [ ] Quem atende o handoff das 9h às 20h (nome e função; o telefone vai só na configuração, não aqui)
- [ ] Atende sábado, domingo e feriado?
- [ ] Tempo máximo aceitável para o humano responder
